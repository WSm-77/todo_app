# knp-todo

Simple API for ```Todo``` application created with ```Spring Boot``` framework.

## Authors

- [stawkey](https://github.com/stawkey)
- [Carexo](https://github.com/Carexo)
- [WSm-77](https://github.com/WSm-77)

## Build

To build docker images use following command:

```shell
docker compose build
```

## Run

To run server and database:

```shell
docker compose up
```
